# Brand assets

- `lac-viet-logo-source.png.base64` is an exact base64 archive of the original PNG supplied by Lucifer. Decode with `base64 -d` (or equivalent) only when a binary PNG is required.
- `lac-viet-logo-production.svg` is the renderable production wrapper embedding the same visual source.
- Do not redraw, recolor, vectorize or substitute the logo without Lucifer approval.
