# WebLacVietbyLucifer

Website chính thức của Lạc Việt Media Agency.

Quy trình thiết kế/triển khai tuân theo `webbyLucifer` v2.2:

- GĐ0: Intake / Discovery
- GĐ1: Full-page UI
- GĐ2: Design System
- GĐ3: Visual-first handoff
- GĐ4–GĐ6: Implementation
- GĐ7: Visual QA / Production

> `main` chỉ là baseline. Thiết kế GĐ2 đang được chuẩn bị trên branch riêng và không tự merge.
